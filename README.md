# SolidityVault

SolidityVault implements scalable, high-performance, auto-scaling architecture with integrated load-balancing and secure, decentralized manager-controller interface.

SolidityVault is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/SolidityVault.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure SolidityVault, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
